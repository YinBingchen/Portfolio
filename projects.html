February 2026

MLB Pitch Classification

Python Pandas Scikit-learn Matplotlib

I built a K-Nearest Neighbors classifier to identify Kevin Gausman’s pitch types using Statcast data. I explored pitch characteristics, created a preprocessing pipeline for missing values, feature scaling, and categorical encoding, and trained the model on 2024 pitches before testing it on data from the first half of 2025.

The model achieved 98.34% test accuracy across 1,806 pitches. I also examined precision and recall for each pitch type, identifying weaker performance on the rare sinker class despite the high overall accuracy.
